# unreal/Data — exported game tables

Generated by `unreal/Tools/export-data` from the web game's TypeScript modules (`src/**`) and the remake's own content
modules (`unreal/GameData/**`, which replace web content modules through the exporter's redirect; see
`unreal/GameData/README.md`). **Never hand-edit**: change the source (remake content in `unreal/GameData`; the web game
under `src/` is read-only for the remake) or the exporter's mapping tables, and re-run
`node unreal/Tools/export-data/run.mjs`. `node unreal/Tools/export-data/run.mjs --check` fails if these files are stale.

## Conventions (all files)

* Envelope: `{"schemaVersion": 1, "source": [TS files read], ...data}`. UTF-8, LF, 2-space indent.
* **TS field names are kept** (camelCase); key and array order = TS insertion order (array order matters wherever
  the web picks uniformly or iterates: item pools, affix pools, quests, triggers, skills, NPC keys).
* Units as in the web: times in **ms**, distances in **tiles** (unless named `…Px`), chances in **0–1** unless the
  field says `…Percent` / the rule is `chance(p)` with `p` in % (`loot_rules.drops`, `chancesArePercent: true`).
* Colours from TS stay **integers** `0xRRGGBB` (e.g. `16737792` = `0xff6600`); colours that were CSS strings stay strings.
* `derived` blocks are **added by the exporter** (DECISIONS C6): explicit fields that replace the web's id /
  substring rules. Each is cross-checked against the real TS code at export time. `port` blocks and the
  `overrides` list carry values decided in `Docs/DECISIONS.md` (decision id quoted) that differ from or extend the web.
* String fields named `note`, `formula`, `…Rule` (when a string) are documentation only.
* `source` names the web module paths a table reads. A web content module listed in `unreal/GameData/redirects.json` is
  loaded from its GameData replacement instead (same path in `source`).
* `remake` block (dark remake, implementation-plan.md §2): present only in a table (or a `CoreTests/golden` map fixture)
  the remake content changed, last key of the file: `{source: str[] (GameData files), modules? {webPath: gameDataPath}
  (redirected modules the file is built from — its `source`, or modules it reads through web code such as the map
  generator's landmarks — whose GameData module no longer matches its Phase 0 snapshot digest in `redirects.json`),
  replaced? / added? / removed?: str[] ("<override table>.<entry key>", from `unreal/GameData/world.ts` overrides;
  "config.<key>" for a `unreal/GameData/config.ts` value that differs from the web chapter's), swept?: str[] (i18n keys
  the orphan sweep dropped), zhTWSupplement? {keys, changed, chars, phrases} (zh-TW: GameData keys converted, how many
  of them the supplement changed, and the size of its character and phrase tables), stringsReplacedWeb? / stringsReplacedPort? / stringsAdded?: int and replacedPortKeys?:
  str[] (i18n: GameData strings that replaced a web string, replaced a port string — those leave `portKeys` — or are
  new)}`. Documentation only; the core does not read it.
* Remake-only fields (`unreal/GameData/types.ts`) appear only once the core can parse them (`REMAKE_SCHEMA` in
  `Tools/export-data/src/main.ts`); until then they are withheld from these files.
* `index.json` lists every file with record counts, byte size and SHA-256, plus the golden fixtures.

Types below: `int`, `num` (double), `str`, `bool`, `T[]`, `{k: T}` (object keyed by id, order significant), `T?` (may be absent/null).
